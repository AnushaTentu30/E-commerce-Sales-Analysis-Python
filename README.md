# E-commerce-Sales-Analysis-Python
Project Overview
This project focuses on analyzing an E-Commerce dataset to understand customer behavior, identify purchasing trends, and derive insights to improve business performance. The analysis was conducted using Python in a Jupyter Notebook, employing data manipulation, visualization, and statistical techniques to uncover key business drivers.

# Objectives
-Explore, clean, and enrich sales data
-Analyze trends in revenue and profit across time, product categories, and customer segments
-Support strategic decisions in sales, marketing, and inventory management

# Tools & Technologies
Python (Pandas, NumPy, Matplotlib, Seaborn)

Jupyter Notebook

Data Visualization & EDA

Statistical Summary & Trend Analysis

# Questions

📅 Converting and Enhancing Date Columns

📈 Monthly Sales Analysis

📦 Sales by Category & Sub-Category

💰 Monthly Profit Trends

📊 Profit by Category & Sub-Category

👥 Sales and Profit by Customer Segment

🔄 Sales-to-Profit Ratio Analysis

# Insights Delivered
-Revealed top customer segments and their contribution to revenue
-Uncovered sales patterns to assist in inventory and marketing planning
-Identified opportunities to improve retention and cross-selling strategies

# Project Structure
e_commerce_project.ipynb – Main notebook with data loading, cleaning, and analysis steps

Visualizations embedded within the notebook for storytelling and insight presentation
